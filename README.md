# lfmp-oauth

OAuth callback page for LFMP's private app "LFMP LeadPro Connector": https://peejayedz.github.io/lfmp-oauth/

After the app is installed, the page shows the one-time code so it can be copied into the local connect script, then clears it from the address bar. It stores nothing, sends nothing and loads nothing from other sites.

Source: `page/oauth/index.html` in the private builder repo. Copy it here as `index.html` after any change.
